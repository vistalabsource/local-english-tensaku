# ローカル英語添削ツール
このソフトは、インターネットに接続できない環境でも、ローカルLLMを使用して英語の文章を添削することができるツールです。

## 必要な環境
**必ずOllamaをインストールしておく必要があります。**
- Pythonで実行する場合
  - Python 3.11以上
  - PySide6
  - Ollama

- EXEで実行する場合
  - Pythonのインストールは不要です。
  - Ollama

## 使い方
[実際のウィンドウ](images/image.png)
1. Ollamaを先に導入しておきます。
2. リリースからZIPをダウンロードし、解凍して「tensaku.exe」を実行します。
3. 添削したい文章を入力し、「添削」ボタンを押すと、添削結果と理由が表示されます。（初回はモデルのインストールが行われるため時間がかかります）
